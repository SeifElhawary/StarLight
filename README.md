# StarLight 🚀

StarLight is a cutting-edge, modern Web3 and NFT gaming platform built to deliver unique digital assets, rare collectibles, and immersive gaming experiences.

## ✨ Features

- **Futuristic Dark Theme Design:** Sleek, high-tech interface tailored for Web3 and gaming enthusiasts.
- **Interactive Carousels (Splide.js):** Smooth products and partner sliders featuring auto-scroll capabilities.
- **Team Section:** Showcases platform founders and core developers with social media integration.
- **Responsive Layout:** Fully optimized for all screen sizes from mobile devices to large desktop monitors.

## 🛠️ Built With

- **React.js** - JavaScript library for building user interfaces.
- **@splidejs/react-splide** - Carousel and slider component.
- **FontAwesome** - Modern vector icons for social links and navigation.
- **CSS3 / Flexbox / Grid** - Custom styling and layout management.
